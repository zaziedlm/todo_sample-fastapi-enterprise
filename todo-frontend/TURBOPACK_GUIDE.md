
## 🔧 **開発ワークフロー**

### **日常開発サイクル**
1. `npm run dev` - Turbopack高速開発
2. コード変更 - 瞬時にHMR反映
3. `npm run type-check` - 型チェック
4. `npm run lint` - コード品質確認

### **機能完成時**
1. `npm run dev:normal` - Webpack環境確認
2. 動作テスト - 本番環境に近い確認
3. `npm run build` - 本番ビルドテスト
4. `npm run start` - 本番動作確認

### **デプロイメント前**
1. `npm run type-check` - 最終型チェック
2. `npm run lint` - 最終品質確認
3. `npm run build` - 本番ビルド生成
4. デプロイメント実行

- 🚫 本番ビルドでは使用不可
- ⚠️ 一部Next.jsプラグインの非対応
- 🔄 Webpackとの微妙な差分
